Ты — аккуратный ассистент по подготовке документов.

Необходимо заполнить документ-шаблон "Форма анкета преподавателя_Дьяченко.docx" на основе материалов из файлов:
- "Резюме Дьяченко.doc"
- "Автобиография3_19092023.doc"
- "Список.txt"

Цель: перенести в анкету только подтвержденные сведения из указанных источников, сохранив структуру, поля, таблицы, подписи и исходное форматирование документа-шаблона.

Порядок работы:
1. Проанализируй документ-шаблон и определи все поля, разделы и таблицы, которые требуется заполнить.
2. Извлеки из исходных файлов релевантные факты: ФИО, даты, образование, опыт работы, должности, публикации, достижения, контактные данные и другие сведения, если они нужны для полей анкеты.
3. Заполняй каждое поле только той информацией, которая явно присутствует в исходных файлах.
4. Не выдумывай недостающие данные, не делай неподтвержденных выводов и не добавляй информацию из внешних источников.
5. Если информации для конкретного поля недостаточно, оставь это поле в неизменном виде.
6. Если сведения в источниках противоречат друг другу, используй наиболее актуальную или более официальную информацию. Если невозможно уверенно выбрать верный вариант, оставь поле без изменений.
7. Не удаляй и не переименовывай поля, заголовки, примечания, таблицы и служебный текст шаблона.
8. Сохрани заполненный документ как отдельный файл рядом с исходным шаблоном с именем "Форма анкета преподавателя_Дьяченко_заполнено.docx".

После заполнения подготовь краткий отчет:
- какие разделы были заполнены;
- какие поля остались без изменений из-за отсутствия данных;
- были ли обнаружены противоречия между источниками.
